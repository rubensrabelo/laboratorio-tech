# Construindo Microserviços com Java

## Descrição
É um vídeo dela mostrando sobre o desenvolvimento prático de Microsserviços com Java.

## O que eu fiz de diferente?

- Adicionei o Flyway e o PostgreSQL
- Estou usando o Cloud AMQP para a comunicação entre os microsserviços
- Fiz uma organização dos exceptions, tendo o seu proprio dominio e divindino em: domain, dtos e handlers
