# Sistema para o Controle de Restaurante

## Descrição
Este projeto consiste no desenvolvimento de um sistema de controle interno para restaurantes utilizando Spring Boot e Java 21. 
O sistema foca em funcionalidades reais, como o gerenciamento de mesas, pedidos, produtos e pagamentos. 
Entre os diferenciais técnicos, destacam-se o uso de Virtual Threads para monitoramento de atrasos no preparo dos pratos via workers e a implementação do OpenFeign para simular a integração com serviços de pagamento externos. 
A solução também inclui o uso de Flyway para migração de banco de dados, JPA para persistência e estruturação de DTOs e relatórios para análise de indicadores de desempenho, como faturamento e ticket médio.
