# Java

Repositório dedicado aos meus estudos e projetos desenvolvidos com **Java** e **Spring Boot**.

Aqui reúno implementações práticas desenvolvidas durante meus estudos, explorando diferentes abordagens, arquiteturas e tecnologias do ecossistema Java. Cada projeto possui um README próprio com detalhes sobre a implementação, arquitetura, tecnologias utilizadas e aprendizados.

---

## Objetivo

Este repositório tem como objetivo documentar minha evolução no ecossistema Java por meio de projetos práticos, explorando assuntos diversos para compreender melhor o funcionamento da plataforma e me aprofundar em diferentes áreas que utilizam essa tecnologia.
