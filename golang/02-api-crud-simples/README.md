# API REST em Go (CRUD)

## Sobre o Projeto
Este projeto foi desenvolvido como parte dos meus estudos da linguagem **Go (Golang)**. O objetivo principal foi implementar uma **API REST simples** capaz de realizar operações de **CRUD** (Create, Read, Update, Delete), utilizando boas práticas nativas da linguagem e integração com banco de dados.
